# Next.js 集成指南

VoerkaI18n 为 Next.js 提供了完整的国际化支持，包括服务端组件（RSC）和客户端组件。

## 安装依赖

```bash
# 安装 CLI 工具（全局）
npm install -g @voerkai18n/cli

# 初始化项目
voerkai18n init

# 启用 Next.js 支持
voerkai18n apply -f nextjs
```

或手动安装：

```bash
npm install @voerkai18n/nextjs @voerkai18n/react
```

## 配置步骤

### 1. 配置翻译组件

Next.js 需要分别配置服务端和客户端翻译组件。

**`languages/client.ts`（客户端入口）：**

```typescript
'use client'
import {
  createClientTranslateComponent,
  ReactTranslateComponentType
} from "@voerkai18n/nextjs/client"
import { VoerkaI18nScope, VoerkaI18nTranslateProps } from '@voerkai18n/runtime'
import formatters from "@voerkai18n/formatters"
import storage from "./storage"
import idMap from "./messages/idMap.json"
import paragraphs from "./paragraphs"
import settings from "./settings.json"
import defaultMessages from "./messages/zh-CN"

const component = createClientTranslateComponent()

const messages = {
  'zh-CN': defaultMessages,
  'en-US': () => import("./messages/en-US"),
  'ja-JP': () => import("./messages/ja-JP"),
}

export const i18nScope = new VoerkaI18nScope<ReactTranslateComponentType>({
  id: "nextjs_client",
  idMap,
  injectLangAttr: false,
  formatters,
  storage,
  messages,
  paragraphs,
  component,
  ...settings
})

export const t = i18nScope.t
export const Translate = i18nScope.Translate as React.FC<VoerkaI18nTranslateProps>
export { VoerkaI18nNextjsProvider } from "@voerkai18n/nextjs/client"
```

**`languages/server.ts`（服务端入口）：**

```typescript
import {
  createServerTranslateComponent,
  ReactServerTranslateComponentType
} from "@voerkai18n/nextjs/server"
import { VoerkaI18nScope, VoerkaI18nTranslateProps } from '@voerkai18n/runtime'
import formatters from "@voerkai18n/formatters"
import storage from "./storage"
import idMap from "./messages/idMap.json"
import paragraphs from "./paragraphs"
import settings from "./settings.json"
import zhCNMessages from "./messages/zh-CN"
import enUSMessages from "./messages/en-US"
import jaJPMessages from "./messages/ja-JP"

const component = createServerTranslateComponent()

const messages = {
  'zh-CN': zhCNMessages,
  'en-US': enUSMessages,
  'ja-JP': jaJPMessages
}

export const i18nScope = new VoerkaI18nScope<ReactServerTranslateComponentType>({
  id: "nextjs_server",
  injectLangAttr: false,
  idMap,
  formatters,
  storage,
  messages,
  paragraphs,
  component,
  ...settings
})

export const t = i18nScope.t
export const Translate = i18nScope.Translate as React.FC<VoerkaI18nTranslateProps>
```

## 使用方式

### 服务端组件

```tsx

import { Translate } from "@/languages/server"

export default async function Home() {
  return (

      <p>
```

### 客户端组件

```tsx
// app/components/LoginForm.tsx
'use client'
import { Translate, useVoerkaI18n } from "@/languages/client"

export default function LoginForm() {
  const { activeLanguage, changeLanguage, languages, t } = useVoerkaI18n()

  return (
    <div>

        <h1>
          <Translate message="用户登录" />

          <Translate message="登录" />
        </button>
      </form>
    </div>
```
```tsx
  )
}
```

## useVoerkaI18n Hook

客户端组件可以使用 `useVoerkaI18n` Hook：

```tsx
'use client'
import { useVoerkaI18n } from '@/languages/client'

function LanguageSelector() {
  const {
    activeLanguage,
    defaultLanguage,
    languages,
    changeLanguage,
    t
  } = useVoerkaI18n()

  return (
    <div>
      <select
        value={activeLanguage}
        onChange={(e) => changeLanguage(e.target.value)}
      >
        {languages.map((lang) => (
          <option key={lang.name} value={lang.name}>
            {lang.title}
          </option>
        ))}
      </select>
    </div>
  )
}
```

## 服务器组件中使用翻译

服务端组件无法使用 Hook，只能使用 `Translate` 组件或 `t()` 函数：

```tsx
import { Translate, t } from "@/languages/server"

export default function ServerComponent() {
  const message = t('服务端翻译')

  return (
    <div>
      <h1>{message}</h1>
      <Translate message="服务端组件翻译" />
    </div>
  )
}
```

## 路由参数中的语言

如果要在 URL 中包含语言参数（如 `/en/about`），可以配置动态路由：

```tsx
// app/[lang]/layout.tsx
import { VoerkaI18nNextjsProvider } from "@/languages/client"

export default function LanguageLayout({
  children,
  params,
}: {
  children: React.ReactNode
  params: { lang: string }
}) {
  return (
    <html lang={params.lang}>
      <body>
        <VoerkaI18nNextjsProvider
          defaultLanguage={params.lang}
          fallback={<div>Loading...</div>}
        >
          {children}
        </VoerkaI18nNextjsProvider>
      </body>
    </html>
  )
}
```

## 避免 hydration 错误

### 常见原因

1. 服务端和客户端渲染的语言不一致
2. 动态内容（如 Date.now()）导致不匹配
3. 浏览器插件注入 DOM

### 解决方案

1. **统一语言源：**

```tsx
// app/layout.tsx
import { VoerkaI18nNextjsProvider } from "@/languages/client"

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en">
      <body>
        <VoerkaI18nNextjsProvider
          fallback={<div>Loading...</div>}
        >
          {children}
        </VoerkaI18nNextjsProvider>
      </body>
    </html>
  )
}
```

2. **禁用 lang 属性注入：**

`languages/settings.json`：

```json
{
  "injectLangAttr": false
}
```

3. **使用 loading fallback：**

```tsx
<VoerkaI18nNextjsProvider fallback={<div>Loading language...</div>}>
  {children}
</VoerkaI18nNextjsProvider>
```

## 常见问题

### Q1: 服务端组件中可以使用 useVoerkaI18n 吗？

**答：** 不可以。`useVoerkaI18n` 是客户端 Hook，只能在客户端组件中使用。服务端组件使用 `Translate` 组件或 `t()` 函数。

### Q2: 如何处理 hydration 错误？

**答：** 确保：
1. 服务端和客户端使用相同的语言源
2. 在 `settings.json` 中设置 `injectLangAttr: false`
3. 使用 `VoerkaI18nNextjsProvider` 的 `fallback` 属性

### Q3: 如何在 API 路由中使用？

```typescript
// app/api/hello/route.ts
import { i18nScope } from "@/languages/server"
import { NextResponse } from 'next/server'

export async function GET(request: Request) {
  const message = i18nScope.t('欢迎')

  return NextResponse.json({
    message
  })
}
```

## 最佳实践

1. **区分服务端和客户端** - 使用对应的入口文件
2. **客户端组件加 'use client'** - 明确标记客户端组件
3. **使用 fallback** - 避免加载时的闪烁
4. **禁用 lang 属性** - 避免 hydration 错误
5. **服务端优先** - 尽可能使用服务端组件
